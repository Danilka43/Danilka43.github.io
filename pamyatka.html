Памятка. Урок 3: Файлы и папки в Windows

Печатная памятка к уроку 3 — распечатайте и держите под рукой

1 📄 Что такое файл?

Файл — это информация (текст, фото, видео, музыка), у которой есть имя и значок.

Примеры: Отчёт.docx, Фото.jpg, Песня.mp3

2 📁 Что такое папка?

Папка (каталог) — контейнер для файлов и других папок. Помогает наводить порядок на компьютере.

3 🗂️ Главные папки

  • «Рабочий стол» — всё, что на экране
  • «Этот компьютер» — все диски (C:, D:, флешки)
  • «Документы», «Загрузки», «Изображения» — системные папки

4 🆕 Как создать папку

ПКМ (правая кнопка мыши) → Создать → Папку → Ввести имя → Enter

5 ✂️ Как скопировать / переместить файл

  • Копировать: Ctrl + C (копировать), Ctrl + V (вставить)
  • Вырезать / переместить: Ctrl + X (вырезать), Ctrl + V (вставить)
  • Перетаскивание мышью: зажать левую кнопку и перетащить в нужную папку

6 ✏️ Как переименовать

ПКМ → Переименовать → Ввести новое имя → Enter

Или нажать F2.

7 🗑️ Как удалить

ПКМ → Удалить → Корзина

Чтобы восстановить — открыть Корзину → ПКМ → Восстановить.

8 ⌨️ Полезные сочетания клавиш

Горячие клавиши Действие
Win + E Открыть Проводник
Ctrl + Shift + N Новая папка
Ctrl + A Выделить всё
Delete Удалить в корзину
Shift + Delete Удалить навсегда (осторожно!)
